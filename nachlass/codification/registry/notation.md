# Notation Registry (symbol concordance)

One row per symbol/notation as used in a specific paper, mapped to the
canonical symbol chosen for the Codified SJAS. The canonical column stays
provisional until the C13 concordance freezes it. Filled from C4 onward.

Columns — **Paper**: corpus key. **Symbol**: the paper's notation (plain
text; describe rather than draw where markdown cannot render it). **Meaning**:
one-line gloss. **Canonical**: codification-wide symbol (provisional before
C13). **Anchor**: page of first use/definition. **Notes**: drift pointers,
collisions with other papers' uses.
